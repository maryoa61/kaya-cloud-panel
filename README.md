# ☁️ پنل مدیریت ابری کایا | Kaya Cloud Subscription Panel

یک پنل تحت وب مدرن، سبک و کاملاً ریسپانسیو مجهز به موتور تزریق آی‌پي‌های تمیز اسکنر و ساختار فرگمنت (Fragment). این سیستم با متصل شدن به **Cloudflare Worker** و حافظه ابری **KV**، لینک‌های سابسکریپشن کلاینت‌ها را به صورت آنی و بدون نیاز به فیلترشکن در شبکه ایران آپدیت می‌کند.

## 🚀 ویژگی‌های کلیدی
- **بدون نیاز به فیلترشکن:** بهینه‌سازی شده برای شبکه داخلی ایران.
- **تزریق خودکار فرگمنت:** قابلیت اعمال پارامترهای `packet` و `interval` روی کانفیگ‌های خروجی.
- **امنیت مبتنی بر لوکال استوریج:** اطلاعات حساس شما در سورس کد عمومی گیت‌هاب ذخیره نمی‌شوند.

## 🛠️ راهنمای فعال‌سازی آنلاین
1. به تب **Settings -> Pages** بروید.
2. برنچ را روی **main** تنظیم کرده و **Save** را بزنید.
3. لینک اختصاصی شما صادر می‌شود.
